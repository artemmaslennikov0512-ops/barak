# БАРАК — Android

Нативная игра на **Kotlin + Jetpack Compose**. Открывается в Android Studio.

## Как запустить

1. Установи [Android Studio](https://developer.android.com/studio)
2. **File → Open** → папка `barak`
3. Дождись Gradle Sync
4. Подключи телефон с USB-отладкой или запусти эмулятор
5. Нажми **Run** ▶️

Если Android Studio предложит создать/обновить Gradle Wrapper — согласись.

## Что уже есть

- Камера (главный экран)
- Карта зоны: двор, столовка, баня, кольщик, мастерская, штаб, ШИЗО, проходная
- Рейды на боссов с **3 стадиями HP** (целый → побитый → избитый)
- Дроп шмота с боссов (заточка, самопал, яд, маска, куртка…)
- Смена камеры по прогрессу
- Наколки у кольщика
- Сохранение прогресса (DataStore)

## Структура

```
app/src/main/java/com/barak/game/
  data/        # боссы, камеры, шмот
  game/        # логика + сохранение
  ui/screens/  # экраны Compose
  MainActivity.kt
app/src/main/assets/concept/  # арт локаций и рейдов
```
